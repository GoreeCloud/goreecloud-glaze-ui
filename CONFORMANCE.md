# GLAZE UI V1.4 Conformance

GLAZE UI V1.4 (`1.4.0`) is the current Stable Glaze UI conformance target. GLAZE UI V1.3 (`1.3.0`) remains the immediately preceding known-good Stable rollback baseline, not the current target.

A consumer is conformant only when its exact repository revision satisfies the applicable V1 design, accessibility, interaction, responsive/form-factor, platform, and production gates. Conformance must fail closed when required evidence is missing, stale, or bound to a different revision.

Promotion of the shared design system to V1.4 does not automatically make any downstream GoreeCloud application conformant. Each consumer must explicitly target `1.4.0` and produce repository-local exact-revision evidence for its supported platforms and production boundary.

By the V1.4 lifecycle decision, subjective optical/polish review, manual assistive-technology validation, physical-device/native-platform qualification, representative real-device performance validation, and qualitative interaction/visual assessment are governed by the V1.4.1 follow-up. Those checks are not represented as passed V1.4.0 evidence, and V1.4.1 cannot become Stable until its own exact-revision acceptance boundary is satisfied.

Privacy Shield, Wardveil Security, Everkeep, GoreeCloud Identity, and GoreeCloud Mesh retain authority over their own truth domains. Glaze UI governs presentation and interaction without manufacturing or strengthening underlying system truth.

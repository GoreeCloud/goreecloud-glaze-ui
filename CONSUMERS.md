# GLAZE UI V1.1 Consumers

The machine-readable authority for current consumer state is `consumers/registry.json`.

The required target for every applicable GoreeCloud user-facing consumer is **GLAZE UI V1.1** (`1.1.1`). Fresh repository-local V1.1.1 adoption and acceptance evidence is required for each consumer; prior V1.1.0, V1.0, or pre-reset Glaze UI evidence does not automatically establish current conformance.

No consumer is production-eligible merely because GLAZE UI V1.1.1 is the current Stable platform target. Each application or service must independently satisfy its applicable rendered, interaction, accessibility, native/platform, product, and release acceptance gates while preserving the authority of the system that owns the underlying state being presented.

GLAZE UI V1.2 Frosted Neutral remains a Candidate. Its package baseline follows the corrected V1.1.1 maintenance release, while its visual provenance remains the unchanged human-approved V1.1.0 baseline. V1.2 is not a production consumer migration target until separately promoted through the governed lifecycle.

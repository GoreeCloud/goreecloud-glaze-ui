# GLAZE UI V1.0

**Release identity:** Official reset baseline at publication  
**Current status:** Historical reset baseline; not consumer-eligible  
**Current Stable successor:** GLAZE UI V1.1 / `1.1.0`

At the time this release record was published, GLAZE UI V1.0 established the sole current Glaze UI product identity and reset the active repository namespace to V1. The baseline retained the intended design-system direction—Glaze Material, ergonomic spatial hierarchy, connected transformation, adaptive expression, accessibility-first interaction, System Shell, and the 32-component catalog—without treating earlier release identities as current V1 evidence.

This file is a historical release record. It does not override the current lifecycle authority in `registry/lifecycle.json` or `VERSION`.

A production release claim for V1.0 had to bind the V1.0 identity to an exact accepted post-reset revision and applicable CI/acceptance evidence. That evidence remains historical and does not make V1.0 the current Stable or consumer-conformance target after a later governed promotion.

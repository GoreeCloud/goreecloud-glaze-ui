## Project-owner lifecycle decision

On 2026-09-06 the GoreeCloud project owner explicitly directed that any remaining GLAZE UI V1.2 blockers be postponed to GLAZE UI V1.3 and that GLAZE UI V1.2 become Stable now. This record implements that scope/lifecycle decision.

The decision **does not** convert unperformed human, manual assistive-technology, physical-device, OEM/compositor, native-adapter, or production-performance qualification into passing evidence. Those qualifications are moved to the V1.3 workstream and are listed in `acceptance/v1.3-deferred-qualification.md`.

## Native-platform boundary

Existing V1 native-platform records were not relabeled as V1.1 evidence. Any V1.1 native implementation or conformance claim remained dependent on its own exact-revision native evidence.

## Environmental Color Memory boundary

Environmental Color Memory remained optional and unimplemented in this first Candidate. Conformance did not depend on environmental content sampling. No remote color derivation, persistent sample history, or semantic inference was authorized by this Candidate.

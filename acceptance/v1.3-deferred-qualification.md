# GLAZE UI V1.3 — Deferred Qualification Workstream

**Status:** Planned follow-up work  
**Created:** 2026-09-06  
**Source decision:** Project-owner direction to postpone remaining V1.2 blockers to V1.3 while promoting V1.2 Stable.

This record carries forward work that was previously treated as blocking V1.2 promotion. It does not imply that GLAZE UI V1.3 is implemented, Release Candidate, Stable, or consumer-eligible.

## Qualification backlog

1. Project-owner/human optical review across Light, Dark, Deep Dark, clarity profiles, artwork/icon collision, and representative reference scenes.
2. Manual assistive-technology sessions for the support matrix actually claimed, including TalkBack, Voice Access, switch access/control, VoiceOver, Orca, or successors where applicable.
3. Physical-device/native/platform qualification for Android/OEM behavior, Linux compositor/window behavior, foldable/posture behavior, and other claimed platform adaptations.
4. Accepted runtime/platform performance budgets plus representative physical-device frame pacing, interaction latency, memory, GPU/compositor, power, thermal, and constrained-device evidence.
5. Native Personalization persistence, system-appearance, and wallpaper-source adapter qualification where a platform implementation claims those integrations.
6. Stable activation/source-namespace cleanup so promoted V1.2-compatible rendering layers can move away from historical Candidate naming only when byte/pixel/behavior equivalence is demonstrated.

## Carry-forward rule

No deferred item may be described later as completed merely because V1.2 is Stable. V1.3 must generate fresh evidence for the exact V1.3 revision and claimed platform/support boundary.

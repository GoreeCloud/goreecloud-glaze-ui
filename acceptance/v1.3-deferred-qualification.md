# GLAZE UI V1.3 — Deferred Qualification Workstream

**Status:** Planned follow-up work; qualification control plane implemented  
**Created:** 2026-09-06  
**Source decision:** Project-owner direction to postpone remaining V1.2 blockers to V1.3 while promoting V1.2 Stable.

This record carries forward work that was previously treated as blocking V1.2 promotion. It does not imply that GLAZE UI V1.3 is implemented, Release Candidate, Stable, consumer-eligible, or accepted by downstream products.

## Current lifecycle boundary

- GLAZE UI V1.2 / `1.2.0` remains current Stable and current official.
- `1.3.0-candidate` remains the planned next target.
- No V1.3 Candidate is active.
- No deferred V1.3 qualification item is represented as passed merely because the control plane exists.
- Downstream consumer conformance and production acceptance remain separate governed decisions.

## Qualification backlog

1. Project-owner/human optical review across Light, Dark, Deep Dark, clarity profiles, artwork/icon collision, and representative reference scenes.
2. Manual assistive-technology sessions for the support matrix actually claimed, including TalkBack, Voice Access, switch access/control, VoiceOver, Orca, or successors where applicable.
3. Physical-device/native/platform qualification for Android/OEM behavior, Linux compositor/window behavior, foldable/posture behavior, and other claimed platform adaptations.
4. Accepted runtime/platform performance budgets plus representative physical-device frame pacing, interaction latency, memory, GPU/compositor, power, thermal, and constrained-device evidence.
5. Native Personalization persistence, system-appearance, and wallpaper-source adapter qualification where a platform implementation claims those integrations.
6. Stable activation/source-namespace cleanup so promoted V1.2-compatible rendering layers can move away from historical Candidate naming only when byte/pixel/behavior equivalence is demonstrated.

## Qualification control plane

The repository now defines a fail-closed V1.3 qualification control plane:

- `contracts/v1.3/deferred-qualification.plan.json` — governing planned workstream and lifecycle rules.
- `contracts/v1.3/qualification-matrix.json` — machine-readable blocking workstreams and required evidence classes.
- `contracts/v1.3/qualification-evidence.schema.json` — exact-revision evidence record contract.
- `evidence/v1.3/README.md` — evidence storage and interpretation boundary.
- `scripts/validate_glaze_v1_3_planned.py` — planned-state and false-promotion validator.
- `.github/workflows/glaze-v1.3-planned-qualification.yml` — CI guard for the planned control plane.

The control plane being implemented does not imply qualification completion. It exists so future evidence can be collected, inspected, superseded, and accepted without weakening the lifecycle boundary.

## Evidence requirements

Every V1.3 qualification claim must generate fresh evidence for the exact V1.3 revision and the platform/support boundary actually claimed. V1.2 evidence may be referenced as historical context but may not be relabeled as a V1.3 pass.

A passing workstream record must identify the exact source revision, provide inspectable evidence references, identify the review authority, resolve or explicitly disposition relevant issues, and be accepted for the lifecycle gate under the V1.3 evidence schema.

While V1.3 remains only `planned`, the repository validator rejects V1.3 evidence records that claim `passed` or that set lifecycle-gate acceptance to true.

## Promotion rule

All six blocking workstreams must have current accepted evidence for the exact promotion revision before V1.3 lifecycle promotion can be considered. Even then, promotion is not automatic: lifecycle promotion remains a separate governed project decision.

## Carry-forward rule

No deferred item may be described later as completed merely because V1.2 is Stable or because the V1.3 control plane has been implemented. V1.3 must generate fresh evidence for the exact V1.3 revision and claimed platform/support boundary.

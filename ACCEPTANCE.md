# GLAZE UI V1.4 Acceptance

GLAZE UI V1.4 / `1.4.0` is the current Official, Stable design-system release. `VERSION`, `registry/lifecycle.json`, `GLAZE_UI_V1_4.md`, and `acceptance/v1.4-stable.md` are the controlling repository authorities for that lifecycle state.

Stable source authority includes the V1.4 Optical Intelligence contract and entrypoints, inherited V1.3 semantic/accessibility/platform foundations, the deterministic Optical Engine, current lifecycle and consumer manifests, and the preserved V1.3 rollback boundary.

The human validation and verification explicitly assigned to V1.4.1—including subjective optical/polish review, manual assistive-technology validation, physical-device/native-platform qualification, representative real-device performance validation, and qualitative interaction/visual assessment—are not represented as passed V1.4.0 evidence. V1.4.1 remains a separate non-Stable follow-up until its own exact-revision acceptance requirements are satisfied.

No downstream GoreeCloud application becomes V1.4-conformant or production-eligible automatically. Each consumer must explicitly target the current Stable release and satisfy its own repository-local exact-revision acceptance boundary for supported platforms.

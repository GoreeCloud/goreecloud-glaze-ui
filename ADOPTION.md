# GLAZE UI V1.2 Adoption

The current Glaze UI adoption target is **GLAZE UI V1.2** (`1.2.0`). GLAZE UI V1.1 (`1.1.0`) remains available as the previous known-good Stable rollback baseline.

Adoption requires repository-local implementation evidence, exact-revision validation, rendered or native acceptance as applicable, accessibility acceptance, supported-form-factor validation, and product-specific production approval. Importing tokens, copying styles, or changing a version label does not establish conformance.

All consumers remain fail-closed in `consumers/registry.json` until V1.2-specific evidence is recorded for the exact consumer revision. The shared V1.2 Stable promotion does not grant downstream conformance automatically.

The remaining human/manual/physical qualification work moved to V1.3 is not a substitute for consumer-specific acceptance and is not recorded as passed V1.2 evidence.

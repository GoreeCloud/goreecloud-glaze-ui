# GLAZE UI V1.3 Adoption

The current Glaze UI adoption target is **GLAZE UI V1.3 — Adaptive Resonance** (`1.3.0`). GLAZE UI V1.2 — Living Frosted (`1.2.0`) remains available as the previous known-good Stable rollback and audit baseline.

Adoption requires repository-local implementation evidence, exact-revision validation, rendered or native acceptance as applicable, accessibility acceptance, supported-form-factor validation, and product-specific production approval. Importing tokens, copying styles, or changing a version label does not establish conformance.

Consumers remain fail-closed in `consumers/registry.json` until V1.3-specific evidence is recorded for the exact consumer revision. An `adoption-required` consumer may retain a complete historical target/revision/evidence record as migration provenance, but that record does not satisfy the current V1.3 target. The shared V1.3 Stable promotion does not grant downstream conformance automatically.

The six unresolved hardening and qualification tracks transferred to V1.3.1 are not a substitute for consumer-specific acceptance and are not recorded as passed V1.3.0 evidence.

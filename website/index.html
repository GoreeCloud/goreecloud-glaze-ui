System Shell

Workspace → Application → System Overlay → System Panel → Critical System

System priority becomes progressively more explicit and solid. Durable content stays readable; transient command, search, control, and feedback chrome may use Glaze. Universal Search and Control Center are bounded System Shell interaction references, not independent application authority. Ordinary composition permits one dominant Glaze panel plus one to three small floating Glaze controls.

Adaptive interaction

Transform rather than resize.

The same navigation concept may become a phone Capsule, tablet rail, desktop sidebar, TV focus dock, compact wearable rotational navigation, or spatial floating surface. Foldable hinges are physical exclusion regions, not decorative gaps.

Mobile

Reachability, safe areas, and a 48px touch-oriented floor.

Tablet

Rail and pane patterns with posture-aware task continuity.

Desktop

Persistent tools, pointer and keyboard support, and resizable workspaces.

TV

Far-view treatment, a 56px floor where applicable, and directional focus.

Wearable

Compact rotational navigation rather than a shrunken phone interface.

Spatial

Depth is supplemental; a fully flat fallback remains operable.

Accessibility and resilience

Effects are optional. Usability is not.

Reduced Transparency resolves optical material to solid hierarchy. Increased Contrast strengthens boundaries. Reduced Motion removes nonessential travel and morphing. 200% text reorganizes instead of clipping. Forced Colors, RTL and localization, Touch Assistance, and no-backdrop or no-depth modes preserve state and task completion.

Exact-revision conformance

Stable V1.2 identity does not equal downstream production acceptance.

Downstream applications must target GLAZE UI V1.2 / 1.2.0 explicitly and generate fresh application-specific evidence for the exact source revision they evaluate. The Stable design-system release does not auto-upgrade consumers or inherit application production acceptance. Qualification explicitly deferred to V1.3 is not represented as passed V1.2 evidence.
